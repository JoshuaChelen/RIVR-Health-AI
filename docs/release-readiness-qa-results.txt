1. Timeline stability and backward compatibility
- Evidence:
  - src/lib/timeline.ts adds normalizeTimelineEvent, normalizeStoredDate, normalizePrecision, tag/data coercion, and safe defaults for missing title/category/source/summary/included_in_previsit/document fields.
  - src/screens/App/TimelineScreen.tsx normalizes rows from Supabase before render.
  - src/screens/App/TimelineEventDetailsScreen.tsx normalizes rows from Supabase before edit/display and saves date_precision as null when occurred_at is cleared.
  - Timeline event edit/save now uses buildTimelineEventSavePayload from src/lib/timeline.ts, covered by automated tests for cleared dates, partial dates, malformed dates, and tag cleanup.
  - src/components/ui/Timeline/TimelineCard.tsx separates the navigation Pressable from the Pre-Visit Switch footer. This removes the nested switch-inside-navigation press target that is a likely mobile gesture conflict/freeze source.
- Status:
  - Implemented.
  - Needs authenticated device/simulator QA to prove the reported mobile freeze is fully resolved.

2. Timeline date and patient age UX
- Evidence:
  - src/lib/timeline.ts adds ageAtIncident, formatTimelineDateMain, and formatTimelineDateDetail.
  - Timeline main view shows incident year by default for older/coarser events.
  - Timeline main view shows detailed date only for day-precision events within the last 24 months.
  - Details screen shows full incident date detail and a sentence including age when DOB is available.
  - Details screen separates Incident date and Reported date rows.
  - Missing incident/reported dates fall back to explicit unknown text.
- Status:
  - Implemented.
  - Needs manual QA with seeded old/new records for exact display confirmation.

3. Clinical highlighting and formatting
- Evidence:
  - src/lib/timeline.ts adds clinicalTagsForEvent and normalizeClinicalLabel.
  - Timeline cards render clinical scan chips for side, body part, diagnosis, surgery, procedure, injury, medication, and symptom signals when detected.
  - Details screen renders the same clinical chips and normalizes clinical data labels from legacy data keys.
- Status:
  - Implemented as deterministic, low-risk local formatting.
  - Detection is intentionally conservative; it does not use AI or broad NLP.

4. Multimodal search UX
- Evidence:
  - src/lib/timeline.ts adds timelineMatchesQuery and healthCardMatchesQuery.
  - src/screens/App/TimelineScreen.tsx adds typed natural search across timeline event text, dates, tags, data payload, document title, clinical tags, and health card / AI summary JSON.
  - Search result count and no-result state are implemented.
  - Health card matches show a small result card linking to Health Summary.
  - Voice search has a release-safe UI entry point behind EXPO_PUBLIC_ENABLE_VOICE_SEARCH=true.
  - When voice search is disabled or unavailable, the app shows a typed-search fallback instead of adding native speech permissions/dependencies.
  - The enabled path uses platform speech support on web only; native mobile keeps the typed-search fallback for App Store safety.
- Status:
  - Typed search implemented.
  - Voice search is feature-flagged with a clear fallback.
  - Automated tests now cover representative natural prompts for timeline and health-card matching.
